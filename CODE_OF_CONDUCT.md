# Code of Conduct

## Our standard

We want this project to be useful, technically rigorous, and welcoming. Contributors and maintainers should:

- Discuss ideas and evidence without attacking people.
- Give clear, constructive, and actionable feedback.
- Respect different experience levels, backgrounds, and viewpoints.
- Avoid harassment, discrimination, threats, sexualized conduct, and deliberate disruption.
- Protect private information and never pressure someone to reveal credentials, customer data, or personal details.

## Scope

This code of conduct applies in repository issues, pull requests, discussions, reviews, and other project spaces managed by RSB-HOLDING.

## Enforcement

Maintainers may edit or remove content, close contributions, restrict participation, or escalate serious conduct when needed to protect the community.

For a private conduct report, use the repository’s [private reporting channel](SECURITY.md) and begin the report title with `Conduct report`. Include only the information necessary to investigate. There is currently no guaranteed response-time SLA.

Good-faith disagreement about technical decisions is not misconduct. Retaliation against someone who reports a concern is unacceptable.
